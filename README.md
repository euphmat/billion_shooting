# BILLION SHOOTING — 1億ブロック惑星破壊

1億ブロックの超巨大惑星「地球」を削り切る、ブラウザで遊べる放置シューティング。

**▶ プレイ: https://euphmat.github.io/billion_shooting/**

## 遊び方

- ブロックに近づくと自動で射撃。壊すとコインと素材が手に入る
- 集めた素材とコインで工房から装備を **製作・強化** (武器 142種 / 素材 172種)
- ワールドマップの四隅には **最難関ダンジョン** が4つ。硬さは異次元だが、超新星・流星群・銀河の刃・特異点を操る超広範囲・超火力の武器が作れる
- 強化 Lv5 ごとに武器が **覚醒** (★1〜★10)。武器ごとに別々の **固有覚醒** (全武器で別物) が目覚めて強くなる
- レベルアップでスキルポイントを獲得し、**スキルツリー** (6系統204種・全パッシブ) を育てる。6系統目「機兵」では、戦域を独立して動く自律機兵 (ハンター / ドリラー / スパイダー / テスラ / ボマー / キャノン / タイタン / ナノマシン) を開発できる
- 惑星の周りには衛星・小惑星・惑星内部ダンジョンなど **64の天体** があり、宝箱からアーティファクト (50種) が手に入る
- 攻撃ボット / コイン回収ボットが自動で手伝ってくれる

## 操作

| | PC | スマホ |
|---|---|---|
| 移動 | WASD / 矢印キー | 右下のバーチャルスティック |
| ズーム | マウスホイール | ピンチ / ＋－ボタン |
| 素材を調べる | ブロックをクリック | ブロックをタップ |
| 工房 | 右パネル | 左下メニュー → 工房 |
| スキルツリー | T キー | 左下メニュー → SKILL |

## スマホ対応 (PWA)

- ホーム画面に追加するとフルスクリーンのアプリとして起動し、オフラインでも遊べる
- セーブはブラウザ内 (IndexedDB) に自動保存。壊した惑星の状態もそのまま残る

## 技術メモ

- ビルド不要の素の HTML / CSS / JavaScript (フレームワークなし)
- `index.html` をブラウザで開くだけでも動作する (PWA 機能には http(s) 配信が必要)

### ファイル構成

```
index.html            画面の骨組み
sw.js                 Service Worker (オフライン用の先読みキャッシュ)
js/manifest.js        バージョン (APP_VERSION) と読み込むファイルの一覧。ここが唯一の定義元
js/main.js            起動 (最後に読み込む)
js/core/              セーブ基盤 (store) / 状態とセーブ (state) / 数値表示 / 派生ステータス / 効果音
js/data/              マスターデータ: 素材 / 惑星 / 装備 / ボット / スキルツリー
js/game/              ゲームの処理: エンティティ / 戦闘 / 衝突 / コイン / ボット / スキル効果 / モンスター / アーティファクト / メインループ
js/render/            キャンバス描画: ブロック / 弾 / 状態異常 / コイン / ダメージ数値
js/ui/                画面の UI: 工房などのパネル / HUD / 通知 / マップ / スキルツリー / スマホ操作
css/                  style.css (共通) と mobile.css (スマホ)
```

- モジュールは使わず、全ファイルが通常の `<script>` としてグローバルを共有する。読み込み順は `js/manifest.js` の `APP_SCRIPTS` の順。
  読み込み時に実行されるコードは、先に読まれたファイルの定義にしか依存できない (関数の中から呼ぶ分には順番は関係ない)
- リリース時は `js/manifest.js` の `APP_VERSION` を上げ、`js/ui/settings.js` のアップデート履歴の先頭に1件足す (公開日 `d` も入れる)
