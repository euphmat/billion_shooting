# BILLION SHOOTING — 1億ブロック惑星破壊

1億ブロックの超巨大惑星「地球」を削り切る、ブラウザで遊べる放置シューティング。

**▶ プレイ: https://euphmat.github.io/billion_shooting/**

## 遊び方

- ブロックに近づくと自動で射撃。壊すとコインと素材が手に入る
- 集めた素材とコインで工房から装備を **製作・強化** (武器 137種 / 素材 168種)
- レベルアップでスキルポイントを獲得し、**スキルツリー** (150種・全パッシブ) を育てる
- 惑星の周りには衛星・小惑星・惑星内部ダンジョンなど **60の天体** があり、宝箱からアーティファクト (50種) が手に入る
- 攻撃ボット / コイン回収ボットが自動で手伝ってくれる

## 操作

| | PC | スマホ |
|---|---|---|
| 移動 | WASD / 矢印キー | 右下のバーチャルスティック |
| ズーム | マウスホイール | ピンチ / ＋－ボタン |
| 素材を調べる | ブロックをクリック | ブロックをタップ |
| 工房 | 右パネル | 左下メニュー → 工房 |
| スキルツリー | T キー | 左下メニュー → SKILL |

## スマホ対応 (PWA)

- ホーム画面に追加するとフルスクリーンのアプリとして起動し、オフラインでも遊べる
- セーブはブラウザ内 (IndexedDB) に自動保存。壊した惑星の状態もそのまま残る

## 技術メモ

- ビルド不要の素の HTML / CSS / JavaScript (フレームワークなし)
- `index.html` をブラウザで開くだけでも動作する (PWA 機能には http(s) 配信が必要)
